# 2026-10-14 · Agent harness and learning docs

**What changed**
- `docs/architecture.md`: one-page map of how the app works, with three request journeys.
- `docs/learn/01–08`: a short lesson per piece of the stack, each pointing at real code.
- `docs/runbook.md`: common failures and fixes.
- `.mcp.json`: Supabase (read-only), Context7 (library docs), Playwright (browser).
  `pnpm mcp:link` scopes Supabase to your own project.
- `.claude/settings.json`: permission allowlist, a hook that keeps real env files out of
  the conversation, and the Braintied plugin marketplace.
- `.claude/agents/`: planner, reviewer, designer.
- `.githooks/`: secret scan before every commit, `pnpm check` before every push.
  Installed automatically by `pnpm install`.
- Skills moved from the repo to the `braintied` plugin so they update in one place.

**Why**
The repo should teach how it works while you build in it, and stop the three expensive
mistakes (leaked keys, broken deploys, unsecured tables) without anyone remembering to.

**How it was checked**
`pnpm check` passes. The env guard hook blocks a `cat .env.local` command and allows
`.env.example`. The pre-commit scan blocks a staged file containing a fake key pattern.
